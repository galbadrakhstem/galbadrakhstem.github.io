# Step-by-step solutions

<p class="lead">A solution is only useful if you can follow every line. On this site no step is skipped: each one is a conversion, a row of a trace table, a line of pseudocode or a reason, and nothing is left to a mark scheme to explain.</p>

## How these solutions are written

<ul class="link-list">
  <li><strong>Every conversion is written out.</strong> Place values or repeated divisions are shown, with the base written as a subscript.</li>
  <li><strong>Algorithms are traced.</strong> Each variable has a column in a trace table and each row records one change, so the output can be checked line by line.</li>
  <li><strong>Cambridge pseudocode.</strong> Algorithms are written with the keywords and conventions of the official pseudocode guide.</li>
  <li><strong>One step per line.</strong> Each line changes one thing, so you can see exactly where an error would appear.</li>
  <li><strong>The answer is checked.</strong> Converting back, re-running the trace with a second input, or a statement of why the result is reasonable.</li>
</ul>
