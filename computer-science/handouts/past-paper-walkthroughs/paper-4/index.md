# Paper 4 — Practical

<p class="lead">Programming on a computer, 75 marks in 2 hours 30 minutes: you write, run and test complete programs in Java, Visual Basic (.NET) or Python, in console mode and without internet or email, and submit the code with evidence of testing.</p>

## What the paper assesses

Calculators must not be used in any 9618 paper. You submit complete program code and evidence of testing, written in Java (console mode), Visual Basic (console mode, a .NET version) or Python (console mode), on a computer without internet or email.

## Syllabus

A Level sections 19–20, except low-level and declarative programming. This paper is examined under whichever of these official documents was in force in your examination series:
