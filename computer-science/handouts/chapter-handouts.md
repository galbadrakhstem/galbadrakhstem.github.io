# Chapter handouts

<p class="lead">One handout per syllabus section, in the order the sections are listed in the 9618 syllabus. Each one states the section and subsections it covers, so you can check it against your own syllabus year before you spend time on it.</p>

  <li>

  </li>
  <li>

## What each chapter handout will contain

Every chapter handout is being written to the same structure:

1. **Syllabus reference** — the section and subsection numbers, with links to the official syllabus documents.
2. **What you need to be able to do** — the learning outcomes as a checklist, in ordinary language.
3. **Notes** — the ideas behind each topic, with the terms the mark scheme expects.
4. **Worked examples** — complete solutions: conversions written out, algorithms traced, pseudocode in full.
5. **Practice questions and solutions** — original questions with full answers.
