## What you need to be able to do

- Write linear and binary searches and insertion and bubble sorts, and explain how their performance depends on the number and order of the data items.
- Write algorithms to find, insert and delete items in stacks, queues, linked lists and binary trees, and describe a graph as an abstract data type.
- Implement abstract data types such as a stack, queue, linked list, dictionary and binary tree from built-in types or other abstract data types.
- Compare algorithms by the time and memory they use, including Big O notation.
- Write and trace recursive algorithms, explain when recursion is beneficial, and describe how a compiler uses a stack to translate recursive code.
