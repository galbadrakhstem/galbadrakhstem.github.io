## What you need to be able to do

- Explain how an operating system maximises the use of resources and how the user interface hides the complexity of the hardware.
- Explain process management: multi-tasking, the running, ready and blocked states, scheduling routines, and the kernel acting as an interrupt handler.
- Explain memory management with virtual memory, paging and segmentation, including page replacement and disk thrashing.
- Explain how an interpreter executes a program without producing a translated version, and the stages of compilation: lexical analysis, syntax analysis, code generation and optimisation.
- Express the grammar of a language with syntax diagrams or Backus–Naur Form, and evaluate expressions in Reverse Polish Notation.
