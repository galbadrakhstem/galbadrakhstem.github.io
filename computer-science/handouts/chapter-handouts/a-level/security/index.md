## What you need to be able to do

- Explain how encryption works, using the terms plain text, cipher text, symmetric and asymmetric key cryptography, public key and private key.
- Explain the purpose of SSL/TLS in client–server communication and the situations in which it is used.
- Explain how a digital certificate is acquired and how it is used to produce digital signatures.
