## What you need to be able to do

- Describe the characteristics of the low-level, imperative (procedural), object-oriented and declarative programming paradigms.
- Write low-level code that uses immediate, direct, indirect, indexed and relative addressing.
- Use object-oriented terminology — classes, objects, properties, methods, inheritance, polymorphism, containment, encapsulation, getters and setters — and write code that uses classes.
- Solve a problem declaratively by writing facts and rules, and write code that satisfies a goal.
- Open, read, write, append to and close files, process serial, sequential and random files, and use exception handling.
