## What you need to be able to do

- Explain why protocols are essential for communication between computers, and how protocol implementation can be viewed as a layered stack.
- Describe the function of each layer of the TCP/IP protocol suite and its use when a message is sent from one host to another across the internet.
- Describe the application-layer protocols HTTP, FTP, POP3, IMAP and SMTP, and peer-to-peer file sharing with BitTorrent.
- Compare circuit switching and packet switching, including the role of a router in packet switching.
