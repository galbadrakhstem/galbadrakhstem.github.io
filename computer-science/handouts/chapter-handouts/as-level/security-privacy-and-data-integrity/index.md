## What you need to be able to do

- Distinguish the security, privacy and integrity of data, and explain the need to secure both data and the computer system.
- Describe security measures, including user accounts, passwords, digital signatures, biometrics, firewalls, anti-virus and anti-spyware software, and encryption.
- Describe threats posed by networks and the internet — malware, hackers, phishing and pharming — and methods to restrict them.
- Explain how data validation and data verification help to protect the integrity of data.
- Use validation checks (range, format, length, presence, existence, limit, check digit) and verification methods (visual check, double entry, parity check, checksum).
