## What you need to be able to do

- Explain the limitations of a file-based approach and how a relational database addresses them, using the terminology of the relational model: entities, tuples, attributes, keys, relationships, referential integrity and indexing.
- Draw entity–relationship diagrams, normalise data to first, second and third normal form, and explain why given tables are or are not in 3NF.
- Describe the features of a DBMS, including the data dictionary, data modelling, logical schema, data integrity and data security, and its developer interface and query processor.
- Understand that a DBMS uses a data definition language and a data manipulation language, and that SQL is the industry standard for both.
- Write SQL to create and change tables with primary and foreign keys, and to query and maintain data held in at most two tables.
