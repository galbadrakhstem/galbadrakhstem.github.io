## What you need to be able to do

- Explain why a computer system needs an operating system and its key management tasks: memory, file, security, hardware and process management.
- Explain the need for utility software and for program libraries, including dynamic link library files.
- Explain the need for assemblers, compilers and interpreters, and the benefits and drawbacks of compiling or interpreting.
- Show awareness that some high-level languages, such as Java, are partially compiled and partially interpreted.
- Describe the features of an integrated development environment for coding, initial error detection, presentation and debugging.
