## What you need to be able to do

- Explain the Von Neumann model and the stored program concept, the general and special purpose registers, the ALU, control unit, system clock and immediate access store, and the address, data and control buses.
- Explain the factors that affect performance, the ports that connect peripherals, the fetch–execute cycle in register transfer notation, and interrupts.
- Explain the relationship between assembly language and machine code, describe a two-pass assembler, and trace simple assembly language programs.
- Use the instruction groups and the immediate, direct, indirect, indexed and relative addressing modes.
- Perform logical, arithmetic and cyclic shifts, and use bit masking to test and set bits to monitor or control a device.
