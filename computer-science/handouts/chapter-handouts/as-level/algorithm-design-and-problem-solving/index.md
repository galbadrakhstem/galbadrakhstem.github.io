## What you need to be able to do

- Explain the need for abstraction and produce an abstract model of a system containing only the essential details.
- Use decomposition to break a problem into sub-problems, leading to program modules (procedures and functions).
- Understand an algorithm as a sequence of defined steps, and record the identifiers it uses in an identifier table.
- Write pseudocode with input, process and output and with sequence, selection and iteration, and convert between structured English, flowcharts and pseudocode.
- Use stepwise refinement and logic statements to express an algorithm at a level of detail from which it can be programmed.
