## What you need to be able to do

- Select suitable data types — INTEGER, REAL, CHAR, STRING, BOOLEAN, DATE — and define, read and write record structures.
- Use one- and two-dimensional arrays with index, lower bound and upper bound, and write pseudocode for a bubble sort and a linear search.
- Explain why files are needed, and write pseudocode to handle text files of one or more lines.
- Understand an abstract data type as a collection of data with a set of operations, and describe stacks, queues and linked lists.
- Add, edit and delete data in a stack, queue and linked list, and describe how each can be implemented with arrays.
