## What you need to be able to do

- Write pseudocode from a flowchart or structured English, including constants, variables, assignment, expressions, input and output.
- Use built-in functions and library routines.
- Write IF statements (with ELSE and nesting), CASE structures, and count-controlled, pre-condition and post-condition loops, and justify the choice of loop.
- Define and use procedures and functions, with parameters passed by value or by reference.
- Use the terminology of procedures and functions — header, interface, parameter, argument, return value — and write efficient pseudocode.
