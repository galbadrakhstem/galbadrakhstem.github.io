## What you need to be able to do

- Explain the purpose of a development life cycle and compare the waterfall, iterative and rapid application development models.
- Describe the analysis, design, coding, testing and maintenance stages.
- Use structure charts to decompose a problem and show the parameters passed between modules, and state-transition diagrams to document an algorithm.
- Identify and correct syntax, logic and run-time errors, and choose testing methods and test data for a test plan.
- Explain the types of maintenance — corrective, adaptive and perfective — and amend an existing program to enhance it.
