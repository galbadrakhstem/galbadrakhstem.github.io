    <h3 id="how-to-prepare">How to prepare</h3>
    <p>Write the base beside each value, preserve leading zeroes when a fixed bit width matters, and show each place-value or division step. For storage questions, identify whether the answer is required in bits or bytes and state any unit convention you use.</p>
