# Step-by-step solutions

<p class="lead">A solution is only useful if you can follow every line. On this site no step is skipped: each one is a relationship, a substitution, a unit conversion, or a reason, and nothing is left to a mark scheme to explain.</p>

## How these solutions are written

<ul class="link-list">
  <li><strong>The relationship comes first.</strong> Each calculation starts from a stated equation — from the data and formulae page or the syllabus — before any number is substituted.</li>
  <li><strong>Units travel with the numbers.</strong> Every quantity is converted to SI units before substitution, and the unit is carried through to the final line.</li>
  <li><strong>One operation per line.</strong> Each line changes one thing, so you can see exactly where an error would appear.</li>
  <li><strong>Sensible precision.</strong> Intermediate values are kept unrounded, and the final answer is given to a precision that matches the data.</li>
  <li><strong>The answer is checked.</strong> A unit check, an order-of-magnitude estimate, or a statement of why the value is reasonable.</li>
</ul>
